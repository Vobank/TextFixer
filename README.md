# TextFixer

Исправление текста по горячей клавише + режим T9 + перевод раскладки.
Тяжёлое исправление считает облако (Google Gemini) — локальный ПК не грузится.
Русский и английский. Все окошки скрыты от записи экрана и стримов.

## Горячие клавиши

| Клавиши | Что делает |
|---|---|
| **Ctrl+Alt+C** | Исправить выделенное (орфография, запятые, ё, Caps Lock, слипшиеся слова). Без выделения — исправит **весь текст поля** (удобно в чатах). |
| **Ctrl+Alt+T** | Вкл/выкл режим **T9** (автозамена опечаток + подсказки при наборе). |
| **Ctrl+Alt+L** | Перевести **раскладку** выделенного (`ghbdtn` → `привет`). |

## Первый запуск

1. Бесплатный ключ: https://aistudio.google.com/apikey → *Create API key*.
2. Запусти `Запуск.bat`. При первом старте вставь ключ в окошко.
3. Иконка **TF** появится в трее.

## Режим T9 (во время набора)

- **Автодополнение:** печатаешь слово → у курсора подсказка → **Tab** принять, **Esc** скрыть.
- **Автоисправление:** слово с опечаткой + пробел → поправится (ловит и 2-3 ошибки).
- Работает по локальному словарю (150k слов, офлайн). Для сложных случаев и запятых — **Ctrl+Alt+C** (облако).

## Автозапуск с Windows

Трей → **«Автозапуск с Windows»** (галочка). Прога будет стартовать в фоне при входе.

## Файлы

- `Запуск.bat` — тихий запуск (иконка в трее).
- `Отладка.bat` — запуск с консолью (видно логи).
- `main.py` — точка входа.
- `textfixer/` — код по модулям:
  - `config.py` — настройки и `config.json`
  - `gemini.py` — облачное исправление
  - `keyio.py` — буфер обмена и эмуляция клавиш
  - `toasts.py` — всплывашки (скрыты от записи)
  - `engine.py` — локальный словарь T9 + перевод раскладки
  - `t9.py` — контроллер режима T9
  - `autostart.py` — автозапуск с Windows
  - `app.py` — сборка всего вместе

## Настройки — `config.json`

| Параметр | Что это |
|---|---|
| `api_key` | ключ Gemini (или переменная `GEMINI_API_KEY`) |
| `model` | модель; при недоступности/лимите подберётся автоматически |
| `copy_delay` | пауза перед копированием, сек |
| `temperature` | 0–1, ниже = правит строже |
| `t9_start` | включать T9 сразу при запуске |
| `t9_autocomplete` / `t9_autocorrect` | подсказки / автозамена (true/false) |
| `t9_phrase` | облачные подсказки-фразы (ест лимит Gemini; по умолчанию off) |
